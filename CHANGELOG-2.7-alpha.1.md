# Biotech 2.7-alpha.1

**Alpha release.** This version is published as an alpha on CurseForge and a prerelease on GitHub, not as the latest stable release.

- Redesign the Terrestrial Habitat with a stepped rear shelter, low-glass open run, lower service pod and a two-wide, three-high entrance.
- Preserve complete 2.5 and 2.6 structures, controller locations, all hatch positions and active-cycle state. Existing blocks are not automatically rebuilt.
- Add imagegen-derived habitat controller textures and fix Service Pipe 3D inventory/hand presentation.
- Validate all three loaders, structure rotations, clearance, ports, save/load and actual in-game captures.
- Add validated alpha/beta/release publishing. Unsuffixed future versions default to stable release; prerelease tags and artifacts remain immutable.
